# Sathtern Security Awareness Website

## 📌 Project Overview

CyberSafe is a responsive cybersecurity awareness website created to provide simple and practical information about common cyber threats and safe online practices.

This project was developed as part of the **Sathtern Virtual Internship Program – Cyber Security Track**.

## 🔐 Topics Covered

- Common Cyber Threats
- Phishing Awareness
- Safe Browsing Tips
- Password Security Guidelines

## ✨ Features

- Simple and user-friendly design
- Navigation menu with section links
- Responsive layout for different screen sizes
- Cybersecurity awareness content
- Phishing prevention tips
- Password security guidance

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## ▶️ How to Use

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the different cybersecurity awareness sections.
